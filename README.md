# Tailwind CSS Projects

Collection of two Next.js projects demonstrating different CSS approaches:

## 1. Vanilla-CSS
- Custom CSS implementation without frameworks
- Features a clean, responsive UI with gradient backgrounds
- Includes navbar, hero section, and call-to-action components
- Built with Next.js 16.1.1 and React 19.2.3

## 2. Finta Landing Page
- Tailwind CSS implementation
- Modern landing page layout
- Component-based architecture with utility classes
- Built with Next.js 16.1.2 and React 19.2.3

## Getting Started

Run either project:
```bash
cd "1. Vanilla-CSS"  # or "2. Finta Landing Page"
pnpm install
pnpm dev
```

Open http://localhost:3000 to view the project.
